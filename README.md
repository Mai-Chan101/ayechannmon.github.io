# Aye Chan Mon — Career Portfolio

This version uses the uploaded reference screenshots as the visual direction:
- warm off-white background
- dark forest green sections
- editorial serif typography
- compact uppercase section labels
- large statement-led headings
- profile summary card
- impact cards
- selected work grid
- professional journey timeline

## Before publishing
Replace `YOUR_EMAIL@example.com`, `YOUR_LINKEDIN_URL`, and `YOUR_CV_URL` in `index.html`.

The portrait currently uses an `AC` placeholder. Replace it with a professional photo when ready.

## GitHub Pages
Upload `index.html`, `styles.css`, and `script.js` to your GitHub Pages repository, then enable Pages from the repository settings.
